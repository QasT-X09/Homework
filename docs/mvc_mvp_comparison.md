# Сравнение MVC и MVP на одном экране задач

## Что проще в MVC
- Быстрее собрать первый экран (меньше интерфейсов и абстракций).
- Удобно, когда экран небольшой и команда маленькая.

## Что сложнее в MVC
- View сильнее зависит от контроллера и его состояния.
- С ростом логики сложнее изолированно тестировать взаимодействие UI/логики.

## Что проще в MVP
- Presenter тестируется без Flutter UI.
- View становится «пассивной»: проще переиспользовать и рефакторить.
- Четче границы ответственности.

## Что сложнее в MVP
- Больше шаблонного кода (интерфейс View, attach/detach).
- Для очень простого экрана может быть избыточно.

## Ручная проверка бизнес-логики (`load` и `add`)
1. Открыть MVC экран: список должен загрузиться (load).
2. Добавить валидную задачу: элемент появляется сверху (add).
3. Нажать добавить с пустым текстом: показать ошибку через `AppErrorHandler`.
4. Повторить те же шаги на MVP экране.
